# Source

These rules come from Robert C. Martin's book *Clean Architecture: A Craftsman's Guide to
Software Structure and Design* (Prentice Hall, 2017). That is a different book from
*Clean Code* (2008).

This folder is an agent packaging of that book, not a reprint. No book text is copied here.
Named rules (Dependency Rule, SOLID, Humble Object, REP/CCP/CRP/ADP/SDP/SAP) are the field's
public vocabulary.

The installable files were adapted from
[btseee/clean-code-skills](https://github.com/btseee/clean-code-skills) v3.0.0 (MIT,
