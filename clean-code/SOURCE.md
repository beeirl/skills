The original package also ships Claude Code hooks in `assets/hooks/claude-settings.json`
and a portable git pre-commit hook in `assets/hooks/pre-commit`. A Grok-compatible
hook file is `assets/hooks/grok-hooks.json`.

Install the Grok hook:

```bash
mkdir -p ~/.grok/hooks
cp ~/.agents/skills/clean-code/assets/hooks/grok-hooks.json ~/.grok/hooks/clean-code.json
```
